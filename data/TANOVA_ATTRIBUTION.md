# Tanova Open Skills Taxonomy attribution

This directory includes `taxonomy.json` from the [Tanova Open Skills Taxonomy](https://github.com/tanova-ai/skills-taxonomy), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Source version: 1.4.11 (last updated 2025-12-28).

JobPatra uses the taxonomy for skill normalization, hierarchy matching, category routing, and scoring weights.

`taxonomy_extensions.json` contains a small, data-only compatibility extension for
well-defined technical skills absent from the downloaded source version. It follows
the upstream schema and is loaded by the same taxonomy service.
